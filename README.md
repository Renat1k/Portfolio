# FluentFable — Portfolio

**[Портфоліо](https://portfolio-y5j.pages.dev/)** · [Українська](https://portfolio-y5j.pages.dev/uk/) · [English](https://portfolio-y5j.pages.dev/en/)

![Головна сторінка FluentFable зі скульптурою Chrome Infinity](./assets/img/portfolio-preview.png)

Статичне двомовне портфоліо: сім проєктів із демо, скриншотами та доступними репозиторіями, профіль і контакти. Дизайн спирається на [`DESIGN.md`](./DESIGN.md). Шрифти локальні: Saira Condensed і Roboto Condensed для кирилиці, Cormorant Garamond для основного тексту, IBM Plex Mono для навігації. Ліцензії — в `assets/fonts/`.

## Мови й контент

- `src/site.mjs`: **`defaultLocale = 'uk'`**. Щоб зробити англійську мовою за замовчуванням, змініть значення на `'en'` і виконайте збірку.
- `/uk/` і `/en/` — сталі адреси мовних версій. Перемикач **UA / EN** зберігає вибір у `localStorage` (`fluentfable.locale`) і переводить на ту саму сторінку зі збереженням параметрів та якоря. Стара головна `/` і старі адреси `/projects/…/` працюють: для першого візиту беруть мову за замовчуванням, для наступних — збережений вибір. Пряме посилання з мовним префіксом завжди відкривається в зазначеній мові.
- Обидві версії, включно з 404, генеруються як готовий HTML. Без JavaScript працюють читання, навігація, посилання на оригінальні зображення та перехід між мовами.
- [`data/profile.json`](./data/profile.json) і [`data/projects.json`](./data/projects.json) — оригінальні дані, технології, медіа та посилання. [`src/copy.mjs`](./src/copy.mjs) — переклади, короткі описи й текст інтерфейсу. Повний опис і всі технології доступні на сторінці кожного проєкту.

## Chrome Infinity

На головній — авторська скульптура з двох переплетених металевих стрічок. Спочатку браузер завантажує тільки відповідний до екрана постер WebP (приблизно 19 або 47 КБ). Кнопка **«Оглянути в 3D»** завантажує локальний WebGL-модуль, карту відбиттів і один із двох GLB:

| Версія | Трикутники | Файл |
|---|---:|---:|
| Стандартна | 13 300 | 163 КБ |
| Полегшена | 6 684 | 84 КБ |

Легша геометрія й обмежена роздільність використовуються на вузьких екранах, сенсорних або малопотужних пристроях та за ввімкненої економії трафіку. Модель можна обертати перетягуванням, кнопками чи стрілками клавіатури; Home повертає початковий ракурс. Кадри малюються лише під час змін. `prefers-reduced-motion` вимикає інерцію та вступний рух. Якщо WebGL недоступний, залишається студійний рендер. Походження ресурсів і повторний експорт описані в [`tools/sculpture/README.md`](./tools/sculpture/README.md).

## Збірка та перевірка

Потрібен Node.js 22+. Для застосунку та звичайної збірки зовнішніх залежностей немає.

```sh
npm ci
npm run build
npm run check
npm run preview
```

Попередній перегляд — http://127.0.0.1:8080/. `npm run dev` відкриває готові сторінки з кореня. Сторінки генеруються з `src/`, а не редагуються вручну. Статична перевірка охоплює обидві мови, старі адреси, метадані, посилання, зображення, оригінальні дані та розміри GLB.

Браузерні перевірки використовують окремі тестові залежності та Chromium:

```sh
npm ci --prefix tests/browser --ignore-scripts
npm run test:browser
```

На Windows сценарій знаходить встановлений Chrome або Edge. Для іншої інсталяції задайте `CHROME_BIN` зі шляхом до Chromium. За замовчуванням перевіряється локальна `dist/`; `PORTFOLIO_URL=https://portfolio-y5j.pages.dev` перемикає тест на опублікований сайт.

## Публікація

Діюча інтеграція **GitHub `main` → Cloudflare Pages `portfolio`** публікує сайт автоматично. Після зміни контенту або шаблонів закомітьте як вихідні файли, так і оновлені `index.html`, `projects/`, `uk/`, `en/`, `404.html`, `sitemap.xml`. `dist/` — локальний артефакт. GitHub Actions перевіряє збірку та відповідність готових сторінок.
